# Frontend Setup

To set up and run the Next.js frontend:

## Installation

```bash
cd frontend
npm install
```

## Configuration

Create a `.env.local` file from `.env.example`:

```bash
cp .env.example .env.local
```

## Development

```bash
npm run dev
```

Visit http://localhost:3000

## Build

```bash
npm run build
npm start
```

## Type Checking

```bash
npm run type-check
```
